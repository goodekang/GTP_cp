Supplementary Figure S1 | Data quality control and graph construction pipeline.

a, Quality control metrics across datasets. Violin plots showing the distribution of four key QC metrics across eight datasets including spatial transcriptomics platforms (HTAN-BRCA, HTAN-CRC, 10x-Visium, 10x-Xenium) and bulk/single-cell cohorts (BRCA, LUAD, COAD, LIRI). 

Top-left: Number of genes detected per sample, ranging from ~15,000 to ~25,000 genes across datasets, indicating sufficient transcriptomic coverage. 

Top-right: Number of cells per sample, showing variation from ~2,000 to ~12,000 cells depending on tissue type and platform.

Bottom-left: Mitochondrial gene fraction (%), with all samples below the quality threshold of 20% (red dashed line), confirming minimal cell death or stress artifacts.

Bottom-right: Library complexity score, with all samples above the 0.5 threshold (red dashed line), indicating adequate sequencing saturation and diverse transcript capture.

Horizontal bars indicate median values. Color coding distinguishes spatial platforms (teal/green tones) from clinical cohorts (purple/orange tones).

b, Neighborhood threshold sensitivity analysis. Dual-axis plot examining the trade-off between model performance (C-index, dark blue circles, left axis) and computational cost (GPU memory in GB, orange squares, right axis) as a function of spatial neighborhood threshold (μm). Performance peaks at 50 μm (red diamond, "Optimal"), achieving C-index = 0.73 on the BRCA validation set (single cancer type, single fold; lower than pan-cancer averages reported in Fig. 3 due to reduced sample size). Larger thresholds increase memory requirements exponentially without proportional performance gains. The gray shaded region indicates the recommended operating range (25–75 μm) balancing accuracy and efficiency.

c, Hierarchical graph compression statistics. Horizontal bar chart comparing the number of nodes at each hierarchical level before (Original, light teal) and after (Compressed, green) graph construction. X-axis shows node count on log₁₀ scale.

- Slide level: 50 → 50 nodes (no compression, preserved for batch structure)
- Region level: 500 → 50 nodes (10× compression)
- Patch level: 10,000 → 500 nodes (20× compression)
- Cell level: 50,000 → 5,000 nodes (10× compression)
- Gene level: 20,000 → 512 nodes (39× compression via pathway aggregation)

Overall, the hierarchical compression achieves ~100× reduction in graph size while retaining biologically meaningful structure, enabling efficient training on standard GPU hardware. Bar intensity reflects information retention at each level.

Abbreviations: QC, quality control; HTAN, Human Tumor Atlas Network; BRCA, breast invasive carcinoma; LUAD, lung adenocarcinoma; COAD, colon adenocarcinoma; LIRI, liver cancer (ICGC); GPU, graphics processing unit.
