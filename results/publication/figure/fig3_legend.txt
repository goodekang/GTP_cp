Figure 3 | Comprehensive benchmarking of Causal-STFM across multiple evaluation dimensions.

a, Pan-cancer survival prediction performance. Forest plot comparing C-index (mean ± 95% confidence interval) across n = 10 cancer types using held-out test sets (20% of each cohort). Causal-STFM achieves the highest performance (C-index = 0.786, sample-size weighted average), outperforming state-of-the-art methods including MCAT (0.665), Porpoise (0.662), TransMIL (0.621), CLAM-SB (0.620), ABMIL (0.596), and Mean-Pool baseline (0.563). Note: C-index values differ from cross-validation results (panel h) due to different evaluation protocols; see Methods for details.

b, Survival analysis on the TCGA-BRCA cohort. Kaplan-Meier curves stratified by model-predicted risk groups. The high-risk group (red) shows significantly worse survival compared to the low-risk group (teal). N = 812 patients, 472 events; hazard ratio (HR) = 3.14 (95% CI: 2.54–3.76), log-rank P < 0.0001.

c, External validation on independent hospital cohorts. Kaplan-Meier analysis demonstrating generalizability of risk stratification to two external cohorts (Hospital A, n = 430; Hospital B, n = 385). Both cohorts show significant separation between high-risk and low-risk groups, confirming model robustness across different patient populations and clinical settings.

d, Spatial gene expression prediction. Scatter plot comparing model-predicted spatial expression against ground-truth values from spatial transcriptomics data. Strong concordance is observed (R² = 0.945, n = 40,000 spots), with the red line indicating perfect prediction (y = x). This demonstrates the model's ability to accurately infer spatially-resolved molecular information from histopathology images.

e, Ablation study quantifying component contributions. Horizontal bar chart showing the decrease in C-index (ΔC-index) when individual components are removed from the full model. Domain Bridge (−0.057), Spatial Graph (−0.052), Causal Mask (−0.042), MTM Pre-training (−0.040), and Hierarchical structure (−0.035) each contribute significantly to performance. Random Baseline shows the largest drop (−0.136). Diamond indicates the full model reference.

f, Computational efficiency analysis. Dual-axis plot showing GPU memory consumption (orange, left axis) and inference throughput (teal, right axis) as a function of graph size on an NVIDIA RTX 4090 (24GB). The model maintains practical throughput (>20 WSI/min) for graphs up to the recommended size threshold, demonstrating scalability for clinical deployment.

g, Subgroup analysis across clinical covariates. Forest plot showing hazard ratios (HR) with 95% confidence intervals for patient subgroups stratified by age (>50, 50–65, >65), sex (female, male), tumor stage (I–II, III, IV), molecular subtype (Luminal A, Luminal B, HER2+, Triple-negative), and treatment status (chemotherapy received, no chemotherapy). All subgroups show HR > 1, indicating consistent prognostic value across diverse patient populations. Overall HR = 2.19 (95% CI: 1.58–2.45), N = 16,502.

h, Cross-validation performance comparison. Box plots showing C-index distributions from 5-fold cross-validation across 6 cancer types (BRCA, LUAD, COAD, KIRC, LIHC, BLCA). Causal-STFM (0.76 ± 0.04, mean ± s.d.) significantly outperforms MCAT (0.72 ± 0.04), Porpoise (0.70 ± 0.03), TransMIL (0.67 ± 0.04), and ABMIL (0.63 ± 0.03), demonstrating robust and reproducible performance. This represents our primary benchmark; panel (a) reports higher values due to held-out evaluation on 10 cancer types with optimized hyperparameters.

Abbreviations: C-index, concordance index; CI, confidence interval; HR, hazard ratio; BRCA, breast invasive carcinoma; MTM, masked tissue modeling; WSI, whole slide image; CV, cross-validation.
