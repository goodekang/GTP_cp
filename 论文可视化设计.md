# 论文可视化设计方案 — Nature Biotechnology 标准
## Causal-STFM: Gene-to-Phenotype Causal Transformer

> **设计原则**：以 Nature/Cell 系列顶刊为标杆，追求「极简形式 × 极密信息」——每一像素都承载信息，每一颜色都传递语义，让审稿人在 30 秒内抓住核心创新，让读者在 3 分钟内完成完整故事线。

### 0.5 统计呈现黄金标准

#### 生存分析必需元素

```
┌──────────────────────────────────────────────────────────────┐
│  SURVIVAL ANALYSIS CHECKLIST                                  │
├──────────────────────────────────────────────────────────────┤
│  □ Sample size (N) per group                                 │

│  □ Number of events per group                                │
│  □ Hazard Ratio (HR) with 95% CI                             │
│  □ Log-rank P-value (exact, not "P < 0.05")                  │
│  □ Risk table at key timepoints (0, 12, 24, 36, 48 mo)       │
│  □ Censoring marks (+) on curves                             │
│  □ Median survival time if reached                           │
│  □ Stratification method (median/tertile/optimal cutoff)     │
└──────────────────────────────────────────────────────────────┘
```

#### P值与效应量格式

```python
def format_stats(p, hr=None, ci=None):
    """Nature-style statistical annotation"""
    if p < 0.0001:
        p_str = "P < 0.0001"
    elif p < 0.001:
        p_str = f"P = {p:.4f}"
    else:
        p_str = f"P = {p:.3f}"
    
    if hr and ci:
        return f"HR = {hr:.2f} (95% CI: {ci[0]:.2f}–{ci[1]:.2f}), {p_str}"
    return p_str
```

## 10. 总结：Nature-Level 可视化核心法则

### 🎯 10 条铁律

1. **一图一故事**：每个 Figure 回答一个明确问题
2. **语义配色**：颜色 = 含义，不是装饰
3. **层级分明**：主证据 > 辅助证据 > 补充细节
4. **数据先行**：先画数据，后加装饰
5. **留白有意**：空白区域也是设计
6. **统计完整**：N, CI, P 缺一不可
7. **可复现**：标注足以让人重现图表
8. **跨图一致**：同一概念同一视觉
9. **简约不简单**：减少元素，增加信息密度
10. **讲故事**：Figures 是连续叙事，不是独立图片
